# .Artisana: Curated Moroccan Treasures

---

## 💡 Project Vision and Business Model

### Core Mission and Curation
The core mission of .Artisana is to bring high-quality, ethically sourced Moroccan artisana directly to the customer. I operate as the sole curator and retailer, personally selecting and purchasing every item directly from talented independent artisans and small workshops across Morocco. This hands-on process ensures exceptional quality and authentic design.

---

## 🛠 Technology Stack

### Front-End: Jetpack Compose
The entire front-end user experience is built using **Jetpack Compose** (Native Android UI Toolkit). This declarative approach was chosen to ensure the high visual fidelity and fluid performance necessary to showcase delicate craftsmanship.

---

## Key Technical Features

### Modern UI/UX
Leveraging Compose to create a smooth, modern, and visually stunning shopping environment.

### Performance & Fluidity
Utilizing Compose's efficient rendering system for fluid animations and fast transitions.

### Image Handling
Optimizing high-resolution image galleries to highlight the intricate details of the products.
